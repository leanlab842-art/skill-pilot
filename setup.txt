========================================
SkillPilot 起動・停止手順
========================================

【前提条件】
・Docker Desktop が起動していること
・.NET SDK がインストールされていること
・Node.js がインストールされていること

========================================

========================================

cd ~/Develop/skill-pilot


========================================
② PostgreSQL(Docker)を起動
========================================

docker compose up -d

起動確認

docker ps

「skill-pilot-db」が Up になっていればOK


========================================
③ バックエンド(API)起動
========================================

新しいターミナルを開く

cd ~/Develop/skill-pilot/backend

dotnet run --project src/SkillPilot.WebApi

起動すると以下のように表示されます

Now listening on:
https://localhost:7191

Swagger

https://localhost:7191/swagger


 1点だけ補足です。Ai:Claude:ApiKeyがdummy-not-setというプレースホルダー値のままのため、
  実際にフォームから求人を登録するとAI分析は「失敗」ステータスになります(これはアプリの
  バグではなく、想定通りの動作です — 求人登録・DB保存・画面遷移・エラー表示までのパイプ
  ライン自体は正常に動いています)。実際のAI分析結果(マッチ率・スキル抽出・学習ロードマッ
  プ)を試したい場合は、以下でご自身のClaude APIキーを設定してください。

  cd backend/src/SkillPilot.WebApi
  dotnet user-secrets set "Ai:Claude:ApiKey" "sk-ant-..."

  設定後はbackendの再起動が必要です。なお、動作確認用に作成したテストユーザー・求人デー
  タはすべて削除済みです(元々あったtest@example.comのみ残っています)。
