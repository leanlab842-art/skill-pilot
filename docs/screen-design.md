## 画面遷移

```
ログイン ⇄ アカウント作成
   │
   ▼
ダッシュボード(プロフィール導線・ログアウトを含む)
   │
   ├─────────────┬─────────────┐
   ▼             ▼             ▼
AI分析        分析履歴      プロフィール(スキル管理)
   │             │
   ▼             ▼
学習ロードマップ  求人詳細 ──▶ 求人編集
                    │
                    ▼
                 求人削除(確認ダイアログ)
```

### 求人編集 [新規]

「AI分析(求人登録)」と同じ入力フォームを流用し、初期値に既存データを表示する。
求人本文を変更して保存した場合は自動的にAI再分析が行われる旨をUI上に注記する。

## v1で採用した設計方針(前回レビュー反映)

- MVP要件にあった「求人編集」「求人削除」「アカウント作成」の画面を追加した
- プロフィール(スキル管理)画面を新設した
- 求人登録・編集画面の入力を「URL貼り付けのみ」から「会社名・タイトル・本文貼り付け」に変更した
- 求人詳細画面でスキルの必須/歓迎・保有/不足を明示するようにした
- 分析履歴にページネーション導線を追加した
